# 验证记录

日期：2026-10-22。公开版 v1.0.0。

- Linux / Python 3.12 环境下，`python -m unittest discover -s tests -v`：**309 项通过**。
- 覆盖：会话/群隔离、队列和取消、文件先收后问、GIF/图片引用、格式标签清理、排版安全边界、搜索配额与来源、语音上传协议、初始化不覆盖数据、隐藏密钥输入及 `/help`。
- 标准聊天和语音转写采用本地模拟 HTTP 端点；测试不发真实 QQ 消息，不调用付费模型。
- Docker Compose 实际解析通过：只有 AstrBot、NapCat、renderer；管理端口均绑定 127.0.0.1；OneBot 未发布；排版网络 `internal: true`。
- `.env` 的美元符号、井号及单引号等特殊字符已检查；Compose 配置序列化可能把 `$` 显示为 `$$`，不要把序列化结果当作密钥原文复制。
- 发布清单检查：没有运行 `.env`、登录状态、会话库、个人管理员身份、服务器凭据或本机 SSH 文件。

尚未在一台全新主机完成本公开版本的完整镜像构建和扫码验收；也未替部署者验证真实 API 的模型能力、额度、视觉、生图和语音识别质量。部署后按运维说明逐项验收，不能把回归测试结果视为这些外部条件已通过。

构建依赖来自公开软件源；离线主机、不同架构或未来的软件源变化需要另行核对。
